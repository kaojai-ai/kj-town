# Highlights
## แจ้งเตือนข้อความ เคส และงานที่ได้รับมอบหมายใน Inbox
KaoJai Inbox จะแจ้งเตือนทีมงานเมื่อมีข้อความใหม่จากลูกค้า เคสใหม่ รายการเร่งด่วน หรืองานที่ได้รับมอบหมาย ดูการแจ้งเตือนเรื่องงานที่มอบหมาย เคส และรายการเร่งด่วนได้จากไอคอนกระดิ่ง พร้อมเลือกการแจ้งเตือนในแอปและแบบ Web Push ตามหมวดหมู่และขอบเขตของข้อความแชตได้

## ปรับแต่ง Chat Widget ให้เหมาะกับแต่ละเว็บไซต์
ตอนนี้คุณปรับแต่ง KaoJai Chat Widget ของแต่ละเว็บไซต์ได้ด้วยข้อความส่วนหัว ข้อความต้อนรับ สี โลโก้ และปุ่มคีย์เวิร์ดเริ่มต้น เพื่อให้ Widget สะท้อนประสบการณ์ที่คุณต้องการมอบให้ผู้เข้าชม
- จัดการ Widget ของหลายเว็บไซต์แยกจากกันได้อย่างอิสระ
- ใช้ตัวอย่างแบบเรียลไทม์บนเดสก์ท็อปและมือถือเพื่อตรวจสอบหน้าตาของ Widget ก่อนนำไปติดตั้งบนเว็บไซต์

**คีย์เวิร์ด:** การแจ้งเตือนสำหรับทีมงานใน KaoJai Inbox, การแจ้งเตือน Web Push สำหรับข้อความลูกค้า, ปรับแต่ง Chat Widget บนเว็บไซต์, ปุ่มคีย์เวิร์ดเริ่มต้นใน Chat Widget, Chat Widget สำหรับหลายเว็บไซต์
